MY DAY — MOBILE WEB APP

This is a Progressive Web App (PWA) package.

To install it on Android:
1. Publish the contents of this folder to a static HTTPS website (GitHub Pages is one free option).
2. Open the HTTPS website in Chrome on your phone.
3. Tap Chrome's three-dot menu > Add to Home screen (or Install app).
4. Confirm. The My Day icon will appear on your home screen.

History:
- Entries are stored in this browser on this device.
- Use History & backup > Export all history regularly.
- On a new phone/browser, open the app and choose Restore backup.
- Clearing browser/site data can erase locally stored history. The backup file protects against that.
- The app works offline after it has been opened once online and its service worker has installed.

Important: this package does not itself publish a website. It must be hosted on HTTPS for installable PWA behaviour.
